Search for prior work on: **$ARGUMENTS**

1. Search `ai/lab/INDEX.md` for matching rows.
2. Search the entry files `ai/lab/*.md` and `ai/lab/journal.md` for the same terms — the ledger is a
   summary and the detail is in the entries.
3. Report, concisely: whether this has been asked before, the verdict, the number behind it, the
   date, and where to read more. If it was refuted or came out inconclusive, say what would have to
   be different for it to be worth asking again.
4. If nothing matches, say so plainly — do not manufacture a near-miss.
