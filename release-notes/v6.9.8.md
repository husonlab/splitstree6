# SplitsTree 6.9.8

## New features

- network view: a **shift-drag** of a leaf moves it on the circle around its neighbour, so the length of its edge
  stays what it was; a leaf of a network that realizes distances can be repositioned without changing a distance
- **Taxon Marks**: a **Node** button draws the mark as the node of each selected taxon, in place of its circle, in
  the network, tree, tree pages, tanglegram and split network views; **Add** keeps putting the mark next to the
  label and **Delete** restores the circle. The choice travels with the display label, as `node="true"` inside
  the `<mark>` tag, so it is saved with the document and can be set by importing display labels
- network view: **Straighten** places every label at the bottom right of its node
- network view: a shift-click (or shortcut-click) on a selected node or edge deselects it, as it does on a label
- **Group Identical Haplotypes** asks which sites to compare: all of them, so that two sequences are identical
  when they agree wherever both have a state, or only the sites that are complete in every sequence, which is
  how PopART groups; the choice is remembered
- the **Simplify Filter** for networks is now the **Shave Filter**: it shaves edges off a network, cheapest first, until
  a target is met. Nothing else about it changes, and documents that name the Simplify Filter still load
- notifications are shown over the document area rather than on screen
- the File menu groups its Export items; the Window menu separates the first item from the list of windows

## Bug fixes

- network view: the labels of a reopened document now sit where they were, relative to their nodes, whether
  they had been placed by hand, by Straighten or by the automatic layout; every label is saved by its offset
  from its node (`lp` edits), and documents saved by earlier versions still load
- network view: switching the grid on, and straightening, now move the nodes only; the labels keep their offsets,
  and the undo of Straighten restores the offsets it found
- network view: once one node has been moved, the positions of all nodes are saved, so a reopened document no
  longer lays some of them out afresh
- network view: dragging a node records its new position once, so the vertex and edge ids of a file are kept and
  a node is no longer restored at the wrong coordinates
- traits: switching a trait off, or all of them, now survives a save and reopen, and restoring a selection no
  longer switches every trait back on
- tree view: a formatted edge is named by its position in the tree, so edge properties are correct after a reload
- pie charts are no longer clipped in SVG and PDF output: an arc is written as a polygon rather than rasterized
- too many notifications are no longer shown at once

## Known issues

- a mark drawn as a node keeps the size of the mark, 14 points unless the label says otherwise; the Taxon Marks
  pane has no size control yet. Edit the display labels directly as a work-around.
- the automatic label layout places a label from the position of its node, not from its extent, so a large node
  mark can touch its label until the labels are placed bottom right or moved
- LogDet requires every state to be observed within a pair of sequences, so it stays undefined for most pairs
  of a strongly skewed protein alignment
