# SplitsTree 6.9.4

- Updated user manual
-

## New features

- PhyloFusion has a new option: Reticulate Placement - options have been renamed to: Normal, Earlier (formerly Largest),
  and Later (formerly Smallest)
- Import Newick trees (and multiple trees) uses the filename to name trees that do not already have a name
- Added a "no comments" option to Newick display and export- this suppresses all comments in a Newick string

## Bug fixes

- Fixed this bug: When reopening a document with multiple TreeView panes, some panes fail to update
- Fixed bug associated with new way of building installers, that prevented users from importing trees
