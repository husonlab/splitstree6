# SplitsTree 6.9.5

- Updated user manual
-

## New features

- Copy to clipboard now preserves comments in Newick strings
- Autumn algorithm now provides a filter for constructing tree-child networks only
- New Network Filter that allows one to filter phylogenies by topolopgy type, namely, tree, normal, tree-child or
  tree-based.
- Rubberband selection (press - wait - and then drag)  of taxa implemented in all tree and network viewers

## Bug fixes

- If a filter results in 0 trees or rooted networks, then downstream viewers can now react correctly to this.
